# NLP Projects

A collection of hands-on natural language processing projects built with Python. Each project has its own folder, notebook, data files, and README with project-specific instructions.

## Projects

| Project | What it explores |
|---|---|
| [Fake News Classification](./Fake%20News%20Classification/) | Classifying news articles as fake or real from their text |
| [Movie Genre Classification with Multi-label Output](./Movie%20Genre%20Classification%20with%20Multi-label%20Output/) | Predicting several genres from a movie plot summary |
| [Quora Question Pairs](./Quora%20Question%20Pairs/) | Detecting whether two questions have the same meaning |
| [SMS Spam Detection](./SMS%20Spam%20Detection/) | Classifying messages as spam or ham, with small web app examples |

## Why this collection?

These projects are learning-oriented examples for exploring common NLP workflows: inspecting text data, cleaning and tokenizing it, engineering features, training classifiers, and trying predictions. Keeping the notebooks together makes it easier to compare approaches to different text problems.

## Good uses

- Learning and demonstrating introductory NLP and machine-learning workflows
- Exploring text classification and multi-label prediction
- Adapting notebook examples for classroom exercises or prototypes

## Limitations

- Results depend on the supplied datasets and should not be assumed to generalize to new populations or real-world data.
- Several notebooks use paths configured for Google Colab or local dataset files; update those paths to match your environment.
- These are educational projects, not production services. Review model quality, data rights, privacy, and operational requirements before adapting them for deployment.

## Getting started

1. Open a project folder and read its README for dataset and run instructions.
2. Open the `.ipynb` notebook in Jupyter Notebook, JupyterLab, or Google Colab.
3. Install that notebook's dependencies and make the dataset available at the path expected by the code.
4. Run the notebook from top to bottom.

Python libraries and dataset requirements vary by project; there is no shared environment or dependency file at this collection level.
